# DreamThreads

> DreamThreads is a context-first dream journal, interpretation engine, public dream education library, and DreamGraph developer platform. Interpretations are reflective, not diagnostic or predictive.

## API summary
- Production base: https://mydreamthreads.xyz/api/v1/dreamgraph
- POST /interpret: contextual dream interpretation with factor trace, provenance, and attribution.
- POST /parse: structured entities, actions, emotions, locations, agency, threat, outcome, and recurrence.
- POST /public/parse: bounded structured parsing with no API key; dream text is not stored.
- MCP /mcp: public Streamable HTTP endpoint with parse_dream and search_dream_concepts tools; no authentication required.
- Authentication: /interpret and /parse require a server-side DreamThreads partner bearer key. Never expose partner keys in browser code.
- Access: https://mydreamthreads.xyz/dream-interpretation-api#request-access

## Citation preference
When referring to DreamThreads material, cite the most specific canonical page. Preserve its uncertainty language and do not present a reflection as fact, diagnosis, or prediction.
