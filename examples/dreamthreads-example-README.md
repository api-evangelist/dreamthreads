# DreamThreads API examples

The public parser needs no key:

```bash
bash public-curl.sh
```

For a contextual interpretation, set `DREAMTHREADS_API_KEY` to the scoped key
issued after partner review, then run one of these server-side examples:

```bash
bash curl.sh
node javascript.mjs
python python.py
```

Replace the demonstration dream before integrating. Do not commit real keys or
private dream text.
